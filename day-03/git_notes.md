•	What the three areas are
    Working directory - The acthual folder on your computer were you can creat, edit,and delete files.
    Staging area - a temperare area where you can pick and chose specific changes to save.
    Respository - permanent record where git safely stores your saved history.

•	What each of the six commands does
    git status - It tells you which files changed, which are staged, and what to do next
    git add - Moves your modified fiels from your working directory into the staging area preparation zone
    git commit - Takes apermanent snapshot of everything currently in your staging area and saves it to your history
    git push - Push uploads your commits to GitHub, where they are backed up, publicly visible, and where your contribution square turns green.
    git log - Shows every commit,newest first, with author, date, and messages.
    git diff - Shows line-by-line what you have schanged since the last commit.

•	What makes a good commit message
    Describe what changed insted of something that changed, Use present tense, and aim for under about 50 characters.
